Customer Intake Process

Prepared for Josh LeClair by John Carlo Caintic · Marketing Strategy & Automation · September 15, 2026

1. What This Covers

A redesigned intake flow for Renee and Kelli, built on top of the field audit. It reuses the fields your account already has wherever the audit found a clean survivor field, and only adds three genuinely new fields, listed in section 5. Ordered the way Renee or Kelli would actually ask it on a first call, a natural conversation, not a form read aloud.

2. Customer Information

  1. "Can I get your name?"
    Field: Contact Name (native) · Text · Required · Basic identification
  2. "What's the best phone number to reach you?"
    Field: Phone (native) · Phone · Required · Primary contact method
  3. "And an email address, so I can send you anything we discuss?"
    Field: Email (native) · Email · Optional · Secondary contact, quote/confirmation delivery

3. Project Information

  1. "What's the address for the project?"
    Field: ZIP Code + Address (native) · Text · Required · Service area confirmation, routing, Mapsly territory
  2. "How did you hear about us?"
    Field: Opportunity Referral · Single select, 32 options · Required · This is the field your account already has and isn't using, fill it in directly at intake instead of relying only on automated tags
  3. "Have we worked together before, or is this your first project with us?"
    Field (new): New or Existing Customer · Single select (New / Existing) · Required · Not currently a dedicated field, recommend adding one rather than inferring it from record history
  4. "What are you looking to have done, blinds, shades, shutters, drapery, or outdoor shading?"
    Field: What type of window treatments are you interested in? (the consolidated survivor of the two duplicate fields) · Single select · Required · Product interest at intake
  5. "Which rooms or areas are we talking about?"
    Field (new): Rooms/Areas Involved · Multi-select or text · Optional · Not currently a dedicated field, useful for scheduling and scoping
  6. "Roughly how many windows or openings are we talking about?"
    Field: Number of Windows (the consolidated survivor of the four window-count fields) · Numerical or single select ranges · Optional · Sizing the job
  7. "Is this a home, or a commercial property?"
    Field: Building Type · Single select (New Construction / Existing Home / Commercial) · Required · Already a strong existing field, keep as-is
  8. "Are you the homeowner, or are you working with a builder on this?"
    Field (new): Homeowner/Builder/Decision-Maker Status · Single select · Optional · Not currently captured cleanly, relevant given the Lennar/builder partner relationship
  9. "Do you have a rough budget in mind, or would you like our team to recommend options first?"
    Field: budget_range (renamed for consistency) · Text or range · Optional · Kept low-pressure, a soft ask, not a qualifying gate
  10. "What's your timeline looking like?"
    Field: How soon are you looking to have your window furnishings installed? · Single select · Optional · Already a strong existing field, keep as-is

4. Scheduling Information

  1. "When works best for you for a free consultation?"
    Field: Would you like to book an appointment? + Date of appointment · Yes/No + Date · Required · Existing fields, keep as-is. Whether "Date of appointment" stays manually-set or gets replaced by the native booking calendar is still open, currently blocked on a separate calendar bug getting fixed first
  2. (Internal, not asked of the customer) Assigned designer
    Field: Assigned User (native) · User select · Required · Standard assignment, no change needed
  3. "Is there anything else about the project we should know before we come out?"
    Field: Anything else we should know? · Large text · Optional · Existing field, catch-all for anything not covered above

5. New Fields This Recommends Adding

Everything else in this intake reuses fields your account already has, either as-is or after the consolidation from the field audit. No new field gets added unless it's listed here, and even these three are simple, single fields, not a return to over-collecting.

  • New or Existing Customer (single select)
  • Rooms/Areas Involved (multi-select or text)
  • Homeowner/Builder/Decision-Maker Status (single select)
