Tag Standardization

1. Why This Matters Now

This has been sitting deferred since late August, it was never blocking anything at the time, but it's the one thing standing between where things are today and starting the Partner nurture campaign you asked for. The plan for that campaign reuses the same Drip and Nurture mechanics already working for end customers, but branches the content and timing based on whether a partner is tagged as a warm lead. That branch only works reliably if there's one consistent tag for it, not several different-looking tags meaning the same thing.

2. What's Confirmed Today

"Partner New Leads Opt-in," the live workflow that handles new partner leads, currently tags them "Drip" as an interim stopgap rather than anything resembling proper warm or cold segmentation. That was a deliberate decision, not an oversight, fixing it as a quick patch was intentionally held off in favor of doing it properly as part of the full Partner campaign build, rather than patching it now and rebuilding it again later. That's still the right call, but it means no actual "warm lead" tagging exists yet anywhere in the live account to build the new campaign's logic against.

3. The Actual Ask

Before the Partner nurture campaign gets built, this needs one decision from you: a single, agreed tag name for a warm partner lead, used consistently everywhere that status needs to be set or checked. Not a technical problem to solve, a naming decision to make once and stick to.

4. Recommended Standard

Use "Warm Lead" as the one tag, applied consistently across every workflow that touches partner lead temperature. Concretely:

  1. Replace the interim "Drip" tag on "Partner New Leads Opt-in" with "Warm Lead" once a partner has engaged but hasn't converted, this is the actual signal the new campaign's branch logic needs to check.
  2. Audit any other workflow that currently tags partner-related leads under a different name for the same status, and bring it in line with this one standard before the campaign build starts, not after.
  3. Treat "Warm Lead" as reserved specifically for partners going forward, keeping it separate from the general customer-facing "nurture" tag already in heavy use for the end-customer Drip/Nurture sequence, so the two audiences never get crossed.

5. What This Unlocks

Once this is settled, the Partner nurture campaign can actually get built: the same proven Drip/Nurture mechanics, branching by whether a partner carries the "Warm Lead" tag, giving partners their own dedicated campaign separate from end customers, exactly what you asked for.

6. What We Need From You

Just a yes on the tag name above, or your own preferred alternative if "Warm Lead" isn't the wording you want. Once that's confirmed, the campaign build itself can be scheduled.
