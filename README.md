# The Window Valet

Dedicated repository for The Window Valet GHL engagement (client: Josh LeClair), scoped to this account only.

## Structure

- `deliverables/` — client-facing PDF reports and roadmaps, current and historical
  - `deliverables/audit/` — earlier audit deliverables from the Week 1 stabilization phase (Aug 17-20), PDF + source HTML pairs
- `memory/` — durable project facts and decisions from the engagement
- `session-notes/` — dated write-ups of engagement status and findings, for picking up context across sessions

Deliverables are also kept locally in `claude-code/the window valet/` on the working machine; this repo is the durable, cross-machine copy.
